# チャットモーダル仕様

## 1. この文書の対象範囲

本書は、トップ画面上で表示されるチャットモーダルの仕様を定義する。

共通の UI 方針は [../common.md](../common.md)、関連するトップ画面仕様は [top.md](./top.md)、API の正本は [../../api/common.md](../../api/common.md) を参照する。

## 2. モーダル概要

チャットモーダルは、トップ画面上で新規チャットまたは既存チャットを表示・操作するためのモーダルである。

UI は LINE のようなチャット画面を前提とし、会話の流れを時系列で見やすく表示する。

- 新規チャット開始ボタン押下時に表示する
- 既存チャットを開くボタン押下時に表示する

## 3. 表示条件

- 新規チャット開始ボタン押下時、作成されたチャットを対象としてモーダルを開く
- 既存チャットを開くボタン押下時、指定されたチャットを対象としてモーダルを開く

## 4. 新規チャット表示

- 新規チャット開始時は、`POST /api/chats` により作成されたチャットを対象にモーダルを開く
- 新規作成直後のモーダルには、対象チャットの表示領域を持つ

## 5. 既存チャット表示

- 既存チャットを開く場合は、`GET /api/chats/{chatId}` を利用して対象チャットを取得する
- モーダル内には対象チャットのチャット履歴を表示する
- 表示対象はログイン済みユーザー自身のチャットに限る

## 6. UI構成

- メッセージ一覧は会話形式で縦に並べて表示する
- ユーザーのメッセージと AI のメッセージは視覚的に区別できるように表示する
- 会話の新しいメッセージが下に積み上がる、LINE ライクな UI を前提とする
- モーダル下部にメッセージ入力欄と送信操作を配置する

## 7. モーダル内でのチャット操作

- モーダル内ではチャット履歴の表示を行う
- モーダル内からメッセージ送信を行う場合は、`POST /api/chats/message` を利用する前提とする
- モーダル内から訂正送信を行う場合は、`POST /api/chats/correct` を利用する前提とする

## 8. 送信可能な内容

- 送信可能な内容はテキストメッセージのみとする
- 画像の送信は行わない
- 画像アップロードやファイル添付機能は今回の仕様範囲外とする

## 9. 範囲外

- モーダルの詳細なレイアウト
- モーダルのサイズやアニメーション
- 未ログイン時のモーダル表示制御
