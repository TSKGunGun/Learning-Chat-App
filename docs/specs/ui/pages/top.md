# トップ画面仕様

## 1. この文書の対象範囲

本書は、トップ画面 `/` の仕様を定義する。

共通の UI 方針は [../common.md](../common.md) を参照する。

## 2. 画面概要

トップ画面は、ログイン成功後にリダイレクトされて表示される画面である。
ログイン済みユーザーのチャット一覧を表示し、既存チャットを開く、新規チャットを開始する、チャットを削除する操作を提供する。

## 3. 表示内容

- ログイン済みユーザーのチャット一覧
- 新規チャット開始ボタン
- 各チャットに対応する開くボタン
- 各チャットに対応する削除ボタン
- チャットモーダル

チャット一覧は、バックエンドの `GET /api/chats` を用いて取得する。
チャット一覧には、各チャットのルーム名を表示する。
新規作成直後のチャットルーム名は `新規チャット` とし、最初のユーザーメッセージ送信後に会話内容から自動生成した名称へ更新する。
チャットモーダルの詳細は [chat-modal.md](./chat-modal.md) を参照する。

## 4. ボタンと操作

### 新規チャット開始ボタン

- トップ画面には新規チャット開始ボタンを配置する
- ユーザーが新規チャット開始ボタンを押下すると、UI は `POST /api/chats` を呼び出す
- 新規チャット作成成功後、UI は作成されたチャットを対象としてチャットモーダルを開く

### 既存チャットを開くボタン

- チャット一覧の各項目に、既存チャットを開くボタンを配置する
- ユーザーが開くボタンを押下すると、対象チャットを表示するチャットモーダルを開く
- 対象チャットの表示には `GET /api/chats/{chatId}` を利用する前提とする
- 既存チャットを開いた場合、チャットモーダル内に対象チャットのチャット履歴を表示する

### チャット削除ボタン

- チャット一覧の各項目に、チャット削除ボタンを配置する
- ユーザーが削除ボタンを押下すると、UI は `DELETE /api/chats/{chatId}` を呼び出す
- 削除成功後、対象チャットは一覧から除外される

## 5. 遷移

- ログイン成功後、UI は `/` へリダイレクトする

本画面の詳細なレイアウトや未ログイン時の挙動は、現時点では本仕様の対象外とする
